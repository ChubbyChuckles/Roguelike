# World Exploration Guide

## Overview

Exploration is at the heart of our roguelike experience. Unlike linear games, our world is designed for **discovery, experimentation, and replayability**. Every run offers new opportunities to uncover secrets, optimize routes, and master the environment.

## 🗺️ Understanding World Structure

### Dungeon Layouts

#### Basic Dungeon Anatomy
```
Typical Dungeon Structure:
├── Entrance Zone (safe, tutorial elements)
├── Exploration Wings (main content areas)
├── Resource Chambers (mining and gathering)
├── Boss Arenas (high-risk, high-reward)
├── Secret Areas (hidden content)
└── Multiple Exits (choice-based progression)
```

#### Layout Types
- **Linear Dungeons**: Straightforward progression with clear paths
- **Branching Dungeons**: Multiple routes with different rewards/risks
- **Open Dungeons**: Large areas with freedom of movement
- **Puzzle Dungeons**: Logic-based progression gates

### Navigation Strategies

#### Mapping Techniques
```
Efficient Exploration:
├── Always map as you go
├── Mark resource locations
├── Note enemy patrol patterns
├── Identify safe rest areas
└── Plan return routes for farming
```

#### Path Optimization
- **Main Path**: Fastest route to objectives
- **Resource Path**: Maximizes gathering opportunities
- **Secret Path**: Focuses on hidden content
- **Safe Path**: Prioritizes low-risk exploration

## ⛏️ Resource Gathering & Mining

### Resource Types

#### Common Materials
| Material | Location | Tool Required | Uses |
|----------|----------|---------------|------|
| **Copper Ore** | Surface caves, shallow mines | Basic pickaxe | Basic weapons/tools |
| **Iron Ore** | Mountain mines, deep caves | Iron pickaxe | Standard equipment |
| **Gold Ore** | Rare veins, elite areas | Steel pickaxe | High-end crafting |
| **Gems** | Crystal caves, secret areas | Diamond pickaxe | Socket enhancements |

#### Organic Resources
| Resource | Location | Harvest Method | Uses |
|----------|----------|----------------|------|
| **Herbs** | Forest clearings, gardens | Hand harvesting | Potions, crafting |
| **Wood** | Forests, dead trees | Axe or hands | Building, fuel |
| **Leather** | Animal dens, farms | Skinning knife | Armor crafting |
| **Meat** | Hunting grounds | Butchering | Food, bait |

### Mining Mechanics

#### Mining Process
```
Mining Workflow:
1. Locate ore vein (visual indicators)
2. Equip appropriate pickaxe
3. Target vein and begin mining
4. Watch for durability warnings
5. Collect dropped materials
6. Repair tools as needed
```

#### Efficiency Tips
- **Tool Quality**: Higher tier tools mine faster and yield more
- **Timing**: Mine during low-threat periods
- **Node Management**: Clear surrounding enemies first
- **Bulk Mining**: Focus on high-density areas for efficiency

### Gathering Optimization

#### Route Planning
```
Optimal Gathering Route:
├── Start at dungeon entrance
├── Clear path to resource chamber
├── Harvest high-value nodes first
├── Work outward in expanding circles
└── Return via cleared path
```

#### Time Management
- **Resource Density**: Calculate yield per minute
- **Travel Time**: Factor in movement between nodes
- **Threat Level**: Balance safety with efficiency
- **Inventory Space**: Don't overfill; return to sell periodically
