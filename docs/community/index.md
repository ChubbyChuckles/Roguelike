## 👥 Community Guidelines

### Code of Conduct

#### Core Principles
```
Respect and Inclusion:
├── Treat all community members with respect
├── Use inclusive language and avoid discrimination
├── Be patient with newcomers and different skill levels
├── Focus on constructive feedback and collaboration
└── Maintain a positive and welcoming environment

Content Standards:
├── Keep discussions appropriate and family-friendly
├── Respect intellectual property and copyrights
├── Avoid spam and excessive self-promotion
├── Use appropriate channels for different topics
└── Follow platform-specific rules and guidelines
```

#### Communication Standards
```
Posting Guidelines:
├── Use clear, descriptive titles for posts
├── Provide context and background information
├── Include relevant details and specifications
├── Search for existing discussions before posting
├── Be responsive to replies and questions
└── Acknowledge helpful responses

Discussion Etiquette:
├── Stay on topic in specialized channels
├── Use thread replies for related discussions
├── Avoid derailing conversations
├── Respect differing opinions
├── Use reactions appropriately
└── Keep criticism constructive
```

### Platform-Specific Rules

#### Discord Rules
```
Server Rules:
├── No harassment, hate speech, or discriminatory content
├── No spam, excessive caps, or emoji abuse
├── No doxxing or sharing personal information
├── No illegal content or piracy discussions
├── Keep content appropriate for all ages
├── Respect channel purposes and topics
├── No excessive @mentioning of users
└── Use voice channels responsibly
```

#### Forum Rules
```
Posting Standards:
├── Use descriptive thread titles
├── Choose appropriate subforums
├── Provide detailed information
├── Include system specifications for tech issues
├── Use spoiler tags for major plot points
├── Respect thread topics and stay on-topic
├── No duplicate threads without adding value
└── Follow posting guidelines for each section
```
