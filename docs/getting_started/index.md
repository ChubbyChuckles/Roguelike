## 🎯 What Makes This Engine Special

### For Players
- **True Freedom**: No class restrictions - mix any weapons, skills, or playstyles
- **Deep Progression**: Infinite leveling with a unique skill maze system
- **Procedural Worlds**: Every run features unique dungeons and challenges
- **Rich Combat**: Timing-based combat with defensive mechanics and weapon specialization

### For Developers
- **Modern Architecture**: Clean, modular C code with comprehensive documentation
- **Developer Tools**: Advanced debug overlay for real-time content editing
- **Testing Framework**: Extensive unit tests with deterministic replay
- **Performance Focus**: Optimized for smooth gameplay across all systems

## 📊 System Requirements

### Minimum Requirements
- **OS**: Windows 10+, Linux (Ubuntu 18.04+), macOS 10.14+
- **CPU**: Dual-core 2.5GHz
- **RAM**: 4GB
- **Storage**: 2GB free space
- **Graphics**: OpenGL 3.3 compatible

### Recommended Requirements
- **OS**: Windows 10+, Linux (Ubuntu 20.04+), macOS 11+
- **CPU**: Quad-core 3.0GHz
- **RAM**: 8GB
- **Storage**: 5GB free space
- **Graphics**: Dedicated GPU with 2GB VRAM
