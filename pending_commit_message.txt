Summary
 - Extend Item Collision Cache with deterministic usage-based prefetch, finer invalidation, and concurrent reader support
 - Add pixel mask frame reset API used by compression tests and tools

Details
Item Collision Cache
 - Prefetch: Added `rogue_item_collision_cache_set_prefetch(int enabled, int budget)` to control bounded, deterministic prefetch. Candidates collected under write lock and queued after unlock; non-recursive fan-out; forward index scan ordering for determinism.
 - Invalidation: Added `rogue_item_collision_cache_invalidate_sprite(const char* sprite_path)` to batch-invalidate all entries sourced from a normalized `assets/...` sprite path.
 - Concurrency: Upgraded to reader/writer locking. Lookups use a shared read lock and upgrade to write on miss with a re-check to avoid duplicate work. LRU/memory accounting performed under write lock; eviction policy unchanged.
 - Hot-reload determinism: On initial build, capture `asset_timestamp` via registered `g_mtime_hook` (if present) rather than filesystem, preventing immediate invalidation under fake mtime tests.

Pixel Mask
 - New `rogue_hit_mask_frame_reset(RoguePixelMaskFrame* f)` frees bits, compressed buffer, distance field, and mipmaps; zeros fields. Used by `test_hit_mask_compression_auto` and future tools.

Docs
 - Roadmap: Added “Milestone 1.2 prefetch + finer invalidation + RW-lock concurrency” section with determinism and test notes.
 - README: Documented `set_prefetch`, `invalidate_sprite`, mtime hook behavior on initial timestamp capture, and `rogue_hit_mask_frame_reset` with usage guidance.

Tests
