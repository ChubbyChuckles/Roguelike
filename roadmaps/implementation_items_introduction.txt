SOPHISTICATED IMPLEMENTATION PLAN: Items JSON Integration
=========================================================

## PROJECT OVERVIEW

Based on comprehensive analysis of the entire codebase, this plan addresses the sophisticated integration of a JSON-first item system that replaces the existing .cfg-based approach while maintaining full compatibility with all interconnected subsystems.

**Technical Foundation Discovered:**
- Advanced item system with 20+ fields: RogueItemDef with comprehensive stats, sprites, rarities, flags, implicits, sockets
- Dual loading infrastructure: rogue_item_defs_load_from_cfg() and rogue_item_defs_load_from_json()
- Sophisticated schema validation: src/content/schema_items.{h,c} with comprehensive JSON validation
- Complex item instances: RogueItemInstance with durability, affixes, enchantments, sockets, quality, GUID tracking
- Deep subsystem integration: vendors, loot generation, crafting, equipment, inventory, persistence
- Migration tooling: tools/items_migrate.c already exists

## RISK MITIGATION & ROLLBACK PLAN

### High-Risk Areas Identified
1. **Item Index Stability**: def_index values must remain stable across JSON loading for save compatibility
2. **Affix Integration**: Complex affix system must work seamlessly with JSON items
3. **Performance**: JSON parsing overhead must not impact game startup time
4. **Schema Evolution**: Future schema changes must maintain backward compatibility

### Rollback Strategy
- Maintain cfg loading paths until JSON system proves stable in production
- Feature flags allow runtime switching between JSON and cfg loading
- Comprehensive test coverage ensures rapid issue detection
- Migration verification tools validate cfg→json conversion accuracy
