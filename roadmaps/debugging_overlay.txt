Debugging Overlay Roadmap – Phase 13.3 (Dependency Graph Visualization)

Status: Complete

Deliverables:
- Content Graph overlay panel with:
	- Advanced filters: id:, path:, group:, hash:, dep:<id>, rev:<id>
	- Node details: direct deps, reverse deps, cached file hash (hex)
	- Group summaries and path-collision markers
	- Actions: Compute All Hashes, Export DOT → build/content_graph.dot
	- Layered SDL preview of multi-hop dependencies (BFS) with depth slider; nodes tinted by group for readability; click-to-drill with breadcrumbs and Back navigation
	- Diagnostics line shows last dependency registration rejection (cycle or path_conflict) via asset_dep tooling

APIs & Modules:
- src/util/asset_dep.{h,c}: dependency registry, hashing, reverse dep queries
- src/debug_overlay/overlay_panels.c: panel_content_graph and helpers
- src/debug_overlay/panels_content_graph.c: SDL preview, exports, filters
- src/debug_overlay/overlay_widgets_*.c: split widget modules; thin aggregator in overlay_widgets.c

Diagnostics API:
- rogue_asset_dep_get_last_reject(kind_buf, kind_cap, id_buf, id_cap, dep_buf, dep_cap) returns the most recent registration rejection reason/id/dep
- rogue_asset_dep_clear_last_reject() resets the diagnostic buffers after they’re shown in tooling
