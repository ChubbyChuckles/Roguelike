# Asset Manager Debug Overlay Panel Implementation Plan
# Roguelike Game Engine - Advanced Asset Management Interface
# Version: 1.0
# Date: September 7, 2025
# Author: Christian "ChubbyChuckles" Rickert

## Overview
This plan builds upon the existing asset management infrastructure to create a sophisticated debug overlay panel for interactive asset management during development. The panel will extend the current `panels_asset_browser.c` implementation and integrate with the existing overlay system, asset manager, and JSON schema validation framework.

## Current Foundation Analysis
- **Existing Asset Browser**: Basic filtering and listing functionality in `panels_asset_browser.c`
- **Overlay System**: Well-established SDL2-based overlay framework with widgets
- **Asset Manager**: Texture/audio loading with ref counting and hot-reload support
- **JSON Schemas**: Content validation system for sprites, audio, levels, etc.
- **Asset Tool CLI**: Command-line inspection and validation utilities

### 10. Platform-Specific File Operations
```c
// Platform-specific file dialog implementations
#ifdef _WIN32
#include <windows.h>
#include <commdlg.h>

bool win32_open_file_dialog(const char* filter, char* out_path, size_t path_size) {
    OPENFILENAMEA ofn = {0};
    char file_buffer[512] = {0};

    ofn.lStructSize = sizeof(ofn);
    ofn.lpstrFile = file_buffer;
    ofn.nMaxFile = sizeof(file_buffer);
    ofn.lpstrFilter = filter;
    ofn.nFilterIndex = 1;
    ofn.Flags = OFN_PATHMUSTEXIST | OFN_FILEMUSTEXIST;

    if (GetOpenFileNameA(&ofn)) {
        strncpy(out_path, file_buffer, path_size - 1);
        return true;
    }
    return false;
}
#endif
```

### 11. GitHub Actions CI Integration
```yaml
# .github/workflows/asset-validation.yml
name: Asset Validation

on:
  push:
    paths:
      - 'assets/**'
      - 'src/asset/**'
      - 'src/debug_overlay/panel_system/**'
  pull_request:
    paths:
      - 'assets/**'

jobs:
  validate-assets:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup SDL2 Dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev

      - name: Configure CMake
        run: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

      - name: Build Asset Tools
        run: cmake --build build --target asset_tool asset_validate

      - name: Run Asset Validation
        run: |
          ./build/asset_validate --manifest asset_manifest.txt --optimize
          ./build/asset_tool checksum-verify --manifest asset_manifest.txt

      - name: Test Overlay Panel
        run: |
          cmake --build build --target test_asset_phase7_tool_cli
          ctest --test-dir build -R "asset" --output-on-failure

      - name: Upload Asset Reports
        uses: actions/upload-artifact@v4
        with:
          name: asset-validation-reports
          path: |
            asset_manifest.txt
            build/asset_*.log
```
