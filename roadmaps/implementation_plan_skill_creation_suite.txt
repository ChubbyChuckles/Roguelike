STATUS DELTA (current)
- Extended optional fields for skills are integrated end-to-end: visuals (cast/projectile/impact/aoe sprites), animation params, audio hooks, AoE, and projectile params. Covered across schema -> runtime loader -> headless-safe debug get/set APIs -> validation -> overlay UI.
- Overlay Skills panel now includes a "Visuals / Advanced" section to edit these fields live. Values persist via overrides JSON and respect validation.
- Validation checks asset existence and parameter bounds (e.g., frame counts, volumes, AoE radius, projectile velocity). Overlay surfaces errors during save and creation flows.
- Overlay Skills panel now shows a sticky "Validation Status" banner that updates live on edits (timing/coeffs/visuals) and after Create/Save/Load, keeping issues visible without opening the Validation panel.

Scope Overview:
Transform the current Skills debug panel into a comprehensive skill creation, editing, testing, and debugging suite for a 2D RPG. Support all standard skill types (melee attacks, ranged projectiles, AoE spells, buffs/debuffs, healing, summoning, passives, ultimates) with real-time visual feedback, sandboxed testing environments, and deep integration with existing game systems (sprites, animations, particles, sound, combat, projectiles). Maintain C performance with modular architecture and extensibility for future skill types.

Goals:
- Full-featured skill definition and editing with rich UI controls
- Real-time skill testing and debugging in sandboxed environments
- Visual skill designer with drag-and-drop effect composition
- Integration with all game systems: sprites, animations, particles, audio, combat
- Performance profiling and optimization tools for skill execution
- Extensible architecture supporting new skill types and mechanics

Non-Goals (for v1):
- Multiplayer skill synchronization (list as extension)
- Full scripting language (use JSON-based effect definitions)
- Real-time collaborative editing (defer to later versions)
