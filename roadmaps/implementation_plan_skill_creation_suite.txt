# SKILL CREATION SUITE IMPLEMENTATION PLAN - COMPREHENSIVE STATUS UPDATE

## Executive Summary
This is a comprehensive, step-by-step implementation plan for the Skill Creation Suite, incorporating all completed work from both the original implementation roadmap and the debug overlay improvements. This plan transforms the current debug panel into a sophisticated skill authoring, testing, and debugging environment with modern UX patterns and professional workflows.

---

## PHASE 1: ARCHITECTURE & CORE DATA MODEL ENHANCEMENT

### 1.1 Extended Skill Definition Schema
- [x] **Skill Type Enum** - Add skill_type enum: MELEE, RANGED, AOE_SPELL, BUFF, DEBUFF, HEAL, SUMMON, PASSIVE, ULTIMATE
- [x] **Visual Asset Properties** - cast_sprite_sheet, projectile_sprite, impact_sprite, aoe_sprite, icon_sprite
- [x] **Animation Properties** - frame_count, frame_duration_ms, animation_loops, sprite_sheet_layout (grid_width, grid_height)
- [x] **Audio Properties** - cast_sound_id, impact_sound_id, loop_sound_id, sound_volume, sound_pitch_variance
- [x] **Area-of-Effect Properties** - aoe_shape (circle/cone/line), aoe_radius, aoe_angle
- [x] **Projectile Properties** - velocity, trajectory_type, pierce_count, homing_strength
- [x] **Schema Validation** - Update schema_skills.{h,c} with new validation rules for each skill type and asset dependencies

### 1.2 Effect Composition System
- [x] **Core Effect Types** - DAMAGE, HEAL, STAT_BUFF, AOE_BLAST, SPAWN_PROJECTILE, TELEPORT (all implemented end-to-end)
- [x] **Conditional Execution** - target_type, health_threshold (caster_health_le_pct), distance_check (max_distance)
- [x] **Timing Controls** - delay_ms, duration_ms, repeat_count, repeat_interval_ms (deterministic pulse scheduling)
- [x] **Effect Stacking** - AURA exclusivity replaces weaker auras and aligns next pulse without double-ticking
- [x] **EffectNode Tree Structure (experimental v1)** - Optional tree (`effect_tree_nodes[8]`) with parent indices enabling hierarchical scheduling. Runtime prefers tree when present; legacy flat nodes retained for backward compatibility. Debug API: get/set tree; validation: bounds + cycle detect. UI/editor serialization pending.
- [x] **SPAWN_ENTITY Effect Type** - Implemented: new enum kind (ROGUE_EFFECT_SPAWN_ENTITY) with fields `spawn_entity_count` (clamped 1..8, default 1) and `spawn_entity_life_ms` (default 5000ms). Backed by a lightweight transient pool (64 cap) in `spawn_entities.c`; entities auto-expire after lifetime. Unit test `test_effectspec_spawn_entity` covers spawn count & expiry. Placeholder foundation for future Summoning system (Phase 6.1).
- [x] **Advanced Effect Validation** - Added authoring-time heuristics: SPAWN_ENTITY field pre-validation (count/life) across primary/flat/tree nodes, non-negative delay_ms, repeat_interval_ms required when repeat_count>0, duration window must cover repeat_count*repeat_interval_ms, and a global effect tree span cap (<=60s) computed via delay chain + window/repeat span to catch runaway authoring.

### 1.3 Skill Execution Engine Enhancement
- [x] **Context Tracking** - cast_position, target_position, affected_entities (clamped to 8)
- [x] **State Machine Core** - IDLE, CASTING, CHANNELING, COOLDOWN, INTERRUPTED states
- [x] **Interrupt System** - rogue_skill_interrupt(id, ctx) with refund mechanics and end FX
- [x] **Performance Profiling** - Lightweight per-skill profiling timestamps
- [x] **Advanced State Machine** - Full skill state machine with queuing system (basic queued activation + global lockout scaffold)
- [x] **Skill Queuing System** - Input buffer based queued re-activation (auto-fires post cast/cooldown)
 - [x] **Enhanced Execution Pathways** - Added lightweight runtime-selectable pathways (default/empowered/utility) for showcase skill (Fireball) via dispatch wrapper in skill_tree.c; exposes set/get/last APIs with deterministic side-effects (buff augment or mini dash) and zero impact when pathway=0.

### 1.4 Sprite Asset Management System
- [x] **Asset Directory Structure** - assets/skills/<skill_name>/{cast,projectile,impact,aoe,icon}/
- [x] **Sprite Sheet Loader** - Grid-based and packed layout support
- [ ] **PNG Sequence Loader** - Frame-based animations (skill_cast_001.png, etc.)
 - [x] **PNG Sequence Loader** - Added `rogue_skill_load_png_sequence` supporting zero-padded and unpadded numeric suffix scanning; current implementation loads independent textures per frame (no atlas yet) and basic negative-path test.
- [x] **Asset Validation System** - File existence checks and path resolution helpers (skills/<id>/...)
- [ ] **Sprite Atlas Generation** - Performance optimization
- [x] **Sprite Atlas Generation** - Added horizontal packing API `rogue_skill_pack_frames_horizontal` with texture consolidation & in-place frame remap; negative-path test (no assets) plus explicit free helper `rogue_skill_free_sequence_frames`.
- [x] **Asset Hot-Reload** - Foundation: polling-based change detection via dependency registry (mtime stat). API `rogue_skill_asset_dep_poll_changes(cb,user)` reports modified assets; higher-level texture reload deferred.
- [x] **Asset Dependency Tracking** - Fixed-cap registry (256) with ref counting + mtime snapshotting. APIs: track/untrack/reset/count/data/poll_changes. Unit test `test_skills_phase1_4_asset_dep_tracking` validates lifecycle & change notification.

### 1.5 Tests
- [x] **Phase 1.3 Tests** - Interrupt semantics and context defaults/clamps
- [x] **Effect Spec Tests** - SPAWN_PROJECTILE, TELEPORT, AURA exclusive, HEAL end-to-end
- [x] **Validation Pipeline Tests** - Skill validation and coefficient gating
- [x] **Enhanced Data Model Tests** - Comprehensive validation for new schema elements (added test_skills_phase1_5_enhanced_schema.c covering sprite/audio/AoE/projectile & effect node timing edge cases, plus negative validation scenarios.)
- [x] **Sprite Loading Tests** - Asset directory and PNG sequence detection (foundation)

	- New: a Preview Target selector lets you switch the live preview between Cast, Projectile, Impact, and AoE sprites regardless of the skill_type inference. Cast previews use grid-sliced frames; other targets default to full-texture single-frame unless grid metadata is present.
